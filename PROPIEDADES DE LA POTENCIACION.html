⚡ POTENCIACIÓN | LEYES

Propiedades esenciales · Ejemplos claros

aⁿ = a · a · a · ... · a (n veces)
a = base (real) · n = exponente (entero)

📐 Propiedades fundamentales

1. Producto misma base
aᵐ · aⁿ = aᵐ⁺ⁿ
Ej: 2³ · 2² = 2⁵ = 32
2. Cociente misma base
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
Ej: 5⁴ ÷ 5² = 5² = 25
3. Potencia de potencia
(aᵐ)ⁿ = aᵐ·ⁿ
Ej: (3²)³ = 3⁶ = 729
4. Potencia de producto
(a·b)ⁿ = aⁿ · bⁿ
Ej: (2·3)² = 2²·3² = 36
5. Potencia de cociente
(a/b)ⁿ = aⁿ / bⁿ
Ej: (4/2)³ = 4³/2³ = 8
6. Exponente cero
a⁰ = 1 (a ≠ 0)
Ej: 7⁰ = 1
7. Exponente negativo
a⁻ⁿ = 1 / aⁿ
Ej: 2⁻³ = 1/8

⭐ Casos especiales

1ⁿ = 1 siempre
0ⁿ = 0 (n>0) cuidado
0⁰ indeterminado
a¹ = a
a^(m/n) = ⁿ√(aᵐ)

🧠 REGLA MNEMOTÉCNICA

✖️ Multiplicación → ➕ SUMA ➗ División → ➖ RESTA ⬆️ Potencia → ✖️ MULTIPLICACIÓN ➖ Negativo → 🔄 INVERTIR

⚠️ Errores comunes

  • (a+b)ⁿ ≠ aⁿ + bⁿ
  • a⁰ = 1 (si a ≠ 0) — ¡no olvides!
  • (aᵐ)ⁿ ≠ aᵐ⁺ⁿ (es multiplicación, no suma)

✅ Ejemplo paso a paso

Calcular: (2³ · 2⁻²)² ÷ 2²
1. Producto: 2³⁻² = 2¹
2. Potencia: (2¹)² = 2²
3. División: 2² ÷ 2² = 2⁰ = 1
